The OECD's October 2020 report [*Cracking the Code: Rulemaking for Humans and Machines*](https://oecd-opsi.org/publications/cracking-the-code/) brought Rules as Code into mainstream policy conversation for the first time. Drawing on initiatives from New Zealand, Australia, France, Canada, and Singapore, it made the case that governments should encode legislation as machine-executable rules — not as a technology experiment, but as a fundamental improvement to how law is made and implemented.

New Zealand's Better Rules programme was the catalyst. Their SmartStart portal, which encoded child entitlement rules as executable logic, demonstrated that precise, computable rules produce better outcomes for citizens and fewer implementation errors for agencies. The OECD report generalised that lesson.

For Legalese, the report validated work we had already been doing. The hard part of Rules as Code is not the software — it is the legal reasoning. Identifying which rules govern a situation, how they interact, and what happens at the edges requires the kind of formal precision that L4 was designed to provide. The movement is young, but the direction is clear.
